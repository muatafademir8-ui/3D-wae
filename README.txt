PANZER STORM 3D PSP - PSPSDK KAYNAK KOD PAKETI (EBOOT.PBP DERLEME)
===================================================================

Bu paket dogrudan Sony PSP donanimi ve PPSSPP emulatoru icin C dilinde
(sceGu / sceGum 3D donanim hizlandirmali) hazirlanmistir.

DERLEME ADIMLARI (PSPSDK / pspdev):
1. Terminalde bu klasorun icine girin.
2. Asagidaki komutu calistirin:
   make
3. Olusan `EBOOT.PBP` dosyasini PSP'de `ms0:/PSP/GAME/PanzerStormPSP/EBOOT.PBP`
   yoluna atin veya PPSSPP ile dogrudan `EBOOT.PBP` dosyasini acin.

KONTROLLER:
- Analog Stick / Yon Tuslari : Tanki sur ve dondur
- L / R Tetik Tuslari        : Kuleyi saga/sola cevir
- X (Cross)                  : 120mm Ana Top Atesi
- O (Circle)                 : Agir Makineli Tufek
- SELECT                     : Tank Garaji & Yukseltme Menusu
